# System Typography Rule

The entire SNP Typing system MUST use **Google Sans** exclusively as the font family for all user interfaces, components, headings, reports, and typography. All other fonts have been removed per user mandate.

## Standard Font Family Stack

```css
font-family: "Google Sans", sans-serif;
```

## Guidelines:
1. **Exclusive Font**: Use `"Google Sans", sans-serif` exclusively everywhere.
2. **Offline Font Files**: Google Sans font files (`GoogleSans-Regular.ttf`, `GoogleSans-Medium.ttf`, `GoogleSans-Bold.ttf`) are bundled locally in `client/public/fonts/`.
3. **Consistency**: Ensure all new components, Ant Design theme tokens (`themeConfig.js`), Tailwind configurations (`tailwind.config.js`), and global styles (`index.css`) adhere strictly to Google Sans.
